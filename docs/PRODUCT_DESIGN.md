# 指定窗口脚本录制工具｜MVP 产品设计文档

## 一、产品目标

提供一个 Windows 桌面工具，让用户在指定窗口中录制重复操作，保存为脚本，并通过自定义快捷键执行或停止。MVP 重点验证“录制一次、检查步骤、重复执行”的完整流程。

## 二、适用场景

适用于界面相对稳定、步骤固定的桌面程序，例如重复点击、填写内容或执行一组快捷键。一次只处理一个目标窗口；脚本库可保存多个脚本。

## 三、主要功能

| 功能 | MVP 要求 |
| --- | --- |
| 选择目标窗口 | 从当前可见窗口中选择一个，并持续显示窗口名称。 |
| 录制操作 | 记录点击、双击、滚轮、按键、组合键和步骤间隔；提供录制暂停与结束操作。 |
| 检查步骤 | 展示步骤列表，允许删除误操作、调整等待时间，并手动补充或编辑“输入文字”步骤。 |
| 脚本库 | 每个脚本独立保存到本机；侧栏列出已保存脚本，可新建、切换和删除。 |
| 执行方式 | 每个脚本可设为单次、指定次数或持续执行；后两种方式可设置轮次间隔。 |
| 快捷键执行 | 为脚本指定可用快捷键，例如 F10；空脚本时按一次开始录制、再按一次结束；已有步骤时按一次从头执行、再按一次停止。 |
| 状态反馈 | 清楚区分待机、录制、暂停、执行和错误状态，并显示当前执行步骤。 |

## 四、核心流程

1. 选择目标窗口并确认；空脚本时在目标窗口按快捷键，或点击「开始录制」后切回目标窗口。
2. 在目标窗口完成操作；需要输入敏感信息时暂停录制。
3. 结束录制，检查、编辑并保存步骤。
4. 在「执行脚本」中选定运行方式、次数与间隔并保存；让目标窗口处于前台，按设定快捷键执行；再次按下即可停止。

## 五、运行规则

- 录制时切离目标窗口，自动暂停；返回后由用户手动继续。
- 只有目标窗口处于前台且仍然存在时才能启动脚本。执行时窗口消失或失去焦点，立即停止。
- 停止快捷键在工具或目标窗口失去焦点后仍须有效。快捷键自身不录入脚本，执行期间不能并行启动第二个任务。持续执行在每轮结束后等待设定间隔，再从第一步开始。
- 快捷键若被系统或其他程序占用，提示用户另选。F12 由 Windows 保留，不列入正式版可选快捷键。
- 中文等输入法文字在第一版允许通过“输入文字”步骤手动补充；其自动录制准确性不作为 MVP 验收条件。

## 六、产品边界

第一版只支持前台窗口、固定步骤、本地脚本和整段脚本的重复执行。不包含条件判断、图像识别、跨窗口操作、后台执行或管理员权限窗口的自动控制。

## 七、完成标准

用户能够在普通桌面窗口中录制点击、按键和滚动，保存多个脚本并从侧栏切换，通过快捷键按单次、指定次数或持续方式执行及停止。窗口切换、关闭或快捷键冲突时，工具会安全停止或明确提示，不向其他窗口继续发送操作。
