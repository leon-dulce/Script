# 指定窗口脚本录制工具｜MVP 产品设计文档

## 一、产品目标

提供一个 Windows 桌面工具，让用户在指定窗口中录制重复操作，保存为脚本，并通过自定义快捷键执行或停止。MVP 重点验证“录制一次、检查步骤、重复执行”的完整流程。

## 二、适用场景

适用于界面相对稳定、步骤固定的桌面程序，例如重复点击、填写内容或执行一组快捷键。一次只处理一个目标窗口；脚本库可保存多个脚本。

## 三、主要功能

| 功能 | MVP 要求 |
| --- | --- |
| 确认目标窗口 | 预先输入目标窗口的完整名称；只有名称匹配的窗口处于前台时，快捷键才能开始录制，不需要鼠标选择窗口。 |
| 录制操作 | 记录点击、双击、滚轮及每次按键按下、重复按下、松开；实时显示每个动作及其等待毫秒数。 |
| 检查步骤 | 录制页面展示可编辑步骤列表，允许删除误操作、调整等待时间，并手动补充或编辑“输入文字”步骤；修改自动保存。 |
| 命名保存 | 结束非空录制后立即弹出名称窗口，确认后保存并进入执行页面；失败保留本次录制供重试，再次录制不覆盖上次脚本。 |
| 脚本库 | 每个脚本独立保存到本机；仅在「执行脚本」页面的侧栏列出全部已保存脚本，可切换和删除。 |
| 执行方式 | 每个脚本可设为单次、指定次数或持续执行；后两种方式可设置轮次间隔。 |
| 快捷键控制 | 为脚本指定可用快捷键，例如 F10；在录制页面按一次开始录制、再按一次结束，在执行页面按一次执行已选脚本、再按一次停止。 |
| 执行画面 | 显示只读步骤列表，随执行持续高亮当前步骤，并显示当前动作、轮次及轮次间隔等待状态。 |
| 状态反馈 | 清楚区分待机、等待目标窗口、录制、暂停、执行和错误状态；执行页面不显示未命名或未保存标签。 |

## 四、核心流程

1. 在「录制与编辑」设置快捷键及目标窗口的完整名称，切到指定窗口按快捷键开始录制。设置完成后不需要按其他按钮；窗口名称为空或前台窗口不匹配时保持待机并说明原因。
2. 在目标窗口完成操作。录制页面实时显示每次按下、重复按下、松开和每个动作之前的等待时间；左右修饰键分别显示。需要输入敏感信息时先结束录制。
3. 再按快捷键结束录制，立即弹出名称窗口。输入 1–100 个字符的名称并确认，保存后进入执行页面；空录制不弹窗、不保存。名称无效或写入失败时保留录制和弹窗，允许修正重试；只有明确确认放弃后才清除待保存内容。已命名脚本的后续步骤编辑自动保存；录制页面不提供开始、结束、新建、重新载入或手动保存按钮。再次录制自动建立另一份脚本。
4. 在「执行脚本」从左侧全部已保存脚本中选择一个，设定运行方式、次数、间隔和快捷键；设置自动保存。切到符合脚本目标程序与内容区尺寸的窗口，按快捷键确认目标并执行；再次按下即可停止。也可先点击「开始执行」，再切到符合要求的目标窗口自动启动。
5. 在执行页面查看只读步骤列表；当前步骤持续高亮，并显示动作与轮次进度。执行页面不提供录制、编辑步骤或手动保存设置的操作。

## 五、运行规则

- 录制窗口名称采用完整匹配且不区分大小写。录制时切离目标窗口，自动暂停；暂停后再按快捷键即结束录制并进入命名流程，不会恢复或改换录制目标。
- 只有目标窗口处于前台、仍然存在，且目标程序及内容区尺寸符合脚本时才能启动脚本。执行时窗口消失、失去焦点或尺寸变化，立即停止。
- 停止快捷键在工具或目标窗口失去焦点后仍须有效。只排除当前控制快捷键及程序注入的键盘事件；其他功能键、左右修饰键、重复按下和松开均单独记录。执行期间不能并行启动第二个任务。持续执行在每轮结束后等待设定间隔，再从第一步开始。
- 等待时间从开始录制计至第一个动作，后续按相邻事件的发生时间计算；支持超过 60 秒的步骤等待，范围为 0–2147483647 毫秒。动作间等待与每轮执行间隔分开设置。
- 快捷键若被系统或其他程序占用，提示用户另选。F12 由 Windows 保留，不列入正式版可选快捷键。
- 中文等输入法文字在第一版允许通过“输入文字”步骤手动补充；其自动录制准确性不作为 MVP 验收条件。

## 六、产品边界

第一版只支持前台窗口、固定步骤、本地脚本和整段脚本的重复执行。不包含条件判断、图像识别、跨窗口操作、后台执行或管理员权限窗口的自动控制。

## 七、完成标准

用户能够先设置窗口完整名称与快捷键，在匹配的普通桌面窗口按快捷键开始和结束录制，实时看到每次按下、松开及等待时间，结束后命名并确认保存多个独立脚本，在执行页面的侧栏切换。执行设置自动保存，可通过快捷键按单次、指定次数或持续方式执行及停止，执行画面会持续高亮当前步骤。名称无效、保存失败、窗口切换、关闭、尺寸不符或快捷键冲突时，工具会保留待保存录制、安全停止或明确提示，不向其他窗口继续发送操作。自动测试之外，必须在实际 Windows 环境可重现地验证上述录制、命名保存、切换、回放、高亮与停止流程；未完成的操作测试须明确记录。
