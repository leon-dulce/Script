# 全域键盘脚本录制工具｜MVP 产品设计文档

## 一、产品目标

提供一个 Windows 桌面工具，让用户跨窗口录制键盘操作，保存为脚本，并通过自定义快捷键执行或停止。MVP 重点验证“录制一次、检查步骤、重复执行”的完整流程。

## 二、适用场景

适用于界面相对稳定、步骤固定的桌面程序，例如填写内容或执行一组快捷键。录制可跨窗口，回放一次处理一个目标窗口；脚本库可保存多个脚本。

## 三、主要功能

| 功能 | MVP 要求 |
| --- | --- |
| 全域录制 | 无需配置目标窗口；设置快捷键后，在任意窗口按快捷键或点击开始录制。 |
| 录制操作 | 记录每个按键首次按下与松开；实时显示每个动作及其等待毫秒数。 |
| 检查步骤 | 录制页面展示可编辑步骤列表，允许删除误操作、调整等待时间，可编辑旧脚本已有的文字步骤，不提供添加文字入口；修改自动保存。 |
| 命名保存 | 结束非空录制后立即弹出名称窗口，确认后保存并进入执行页面；失败保留本次录制供重试，再次录制不覆盖上次脚本。 |
| 脚本库 | 每个脚本独立保存到本机；仅在「执行脚本」页面的侧栏列出全部已保存脚本，可切换和删除。 |
| 执行方式 | 每个脚本可设为单次、指定次数或持续执行；后两种方式可设置轮次间隔。 |
| 快捷键控制 | 为脚本指定可用快捷键，例如 F10；在录制页面按一次开始录制、再按一次结束，在执行页面按一次执行已选脚本、再按一次停止。 |
| 执行画面 | 显示只读步骤列表，随执行持续高亮当前步骤，并显示当前动作、轮次及轮次间隔等待状态。 |
| 状态反馈 | 清楚区分待机、等待目标窗口、录制、执行和错误状态；执行页面不显示未命名或未保存标签。 |

## 四、核心流程

1. 在「录制与编辑」设置快捷键，按快捷键或点击「开始录制」直接开始，无需设置窗口名称。
2. 自由切换窗口完成键盘操作。录制页面实时显示每个按键首次按下与松开和每个动作之前的等待时间；左右修饰键分别显示。需要输入敏感信息时先结束录制。
3. 再按快捷键结束录制，立即弹出名称窗口。输入 1–100 个字符的名称并确认，保存后进入执行页面；空录制不弹窗、不保存。名称无效或写入失败时保留录制和弹窗，允许修正重试；只有明确确认放弃后才清除待保存内容。已命名脚本的后续步骤编辑自动保存；录制页面提供开始／停止录制按钮，不提供新建、重新载入或手动保存按钮。再次录制自动建立另一份脚本。
4. 在「执行脚本」从左侧全部已保存脚本中选择一个，设定运行方式、次数、间隔和快捷键；设置自动保存。新键盘脚本可切到任意普通目标窗口，旧脚本仍需符合原程序与尺寸；按快捷键确认目标并执行；再次按下即可停止。也可先点击「开始执行」，再切到符合要求的目标窗口自动启动。
5. 在执行页面查看只读步骤列表；当前步骤持续高亮，并显示动作与轮次进度。执行页面不提供录制、编辑步骤或手动保存设置的操作。

## 五、运行规则

- 录制不绑定窗口，切换焦点、改变尺寸、关闭窗口均不暂停；开始与停止可使用同一快捷键或录制按钮。
- 只有目标窗口处于前台、仍然存在，且旧脚本的目标程序及尺寸符合保存要求时才能启动脚本。执行时窗口消失、失去焦点或尺寸变化，立即停止。
- 停止快捷键在工具或目标窗口失去焦点后仍须有效。只排除当前控制快捷键及FlowKey 自己回放的键盘事件；其他功能键、左右修饰键、首次按下和松开均单独记录，长按重复信号不新增步骤。执行期间不能并行启动第二个任务。持续执行在每轮结束后等待设定间隔，再从第一步开始。
- 等待时间从开始录制计至第一个动作，后续按相邻事件的发生时间计算；支持超过 60 秒的步骤等待，范围为 0–2147483647 毫秒。动作间等待与每轮执行间隔分开设置。
- 快捷键若被系统或其他程序占用，提示用户另选。F12 由 Windows 保留，不列入正式版可选快捷键。
- 录制保存物理按键事件，不保证还原输入法最终文字；保留旧文字步骤的回放兼容性，移除添加文字入口。

- 双击发布的 FlowKey.exe 默认请求管理员权限，用户允许后启动，取消则不启动。源码测试宿主的一般权限模式切到管理员程序时，录制页显示明确提醒；结束并保存录制后，可点击「以管理员模式重新开启」。Windows 授权由用户完成，取消保留当前窗口，录制及待命名期间禁用重启。

## 六、产品边界

第一版只支持前台窗口、固定步骤、本地脚本和整段脚本的重复执行。不包含条件判断、图像识别、跨窗口自动回放、后台执行或绕过游戏保护的控制。管理员窗口须由用户授权，以相同管理员权限运行 FlowKey。

## 七、完成标准

用户能够设置快捷键后，在任意普通桌面窗口按快捷键，或使用开始／停止按钮录制，实时看到每次按下、松开及等待时间，结束后命名并确认保存多个独立脚本，在执行页面的侧栏切换。执行设置自动保存，可通过快捷键按单次、指定次数或持续方式执行及停止，执行画面会持续高亮当前步骤。名称无效、保存失败、执行时窗口切换、关闭、尺寸不符或快捷键冲突时，工具会保留待保存录制、安全停止或明确提示，不向其他窗口继续发送操作。自动测试之外，必须在实际 Windows 环境可重现地验证上述录制、命名保存、切换、回放、高亮与停止流程；未完成的操作测试须明确记录。

## 设置：执行窗口流程

设置作为独立导航页，仅包含执行窗口切换。开始与结束各两张选项卡，共四种组合；自动开始时显示窗口选择器与刷新入口。下方以一句流程预览说明效果，显示自动保存或失败状态。运行、等待目标窗口和命名期间禁用设置。结束包含自然完成、手动停止和异常停止；持续执行在停止时才处理。关闭应用不重新唤起应用。

设置入口固定在侧栏底部、本地脚本库提示卡上方。自动切窗期间显示等待状态并允许取消；未找到指定窗口时显示其名称和开启／重选指引。
