# 指定窗口脚本录制工具｜MVP 技术方案

## 一、目标与范围

本方案落实[产品设计文档](PRODUCT_DESIGN.md)中的 Windows 桌面 MVP：选择一个前台窗口，录制并编辑固定步骤，保存到本机，再通过快捷键执行或停止。目标是先完成可验证的端到端流程，不追求对所有应用的通用自动化能力。

## 二、推荐技术路线

| 层次 | 选择 | 原因 |
| --- | --- | --- |
| 桌面宿主 | C#、.NET 10 LTS、WPF | 适合 Windows 桌面应用，便于管理窗口、消息循环和后台任务。 |
| 界面 | WebView2 加 HTML/CSS/JavaScript | 可沿用现有 HTML Demo 的视觉设计，由桌面宿主提供系统功能。 |
| 系统能力 | Windows Win32 API，通过 C# 调用 | 负责窗口识别、键鼠事件、全局快捷键与模拟输入。 |
| 脚本存储 | 本地 JSON 文件 | 便于检查、编辑和添加版本号；MVP 不需要数据库或云端。 |

现有 [HTML Demo](../index.html) 是交互原型，其模拟录制与浏览器本地存储不应直接作为正式实现。正式版由界面向桌面宿主发送明确的操作请求，再由宿主把状态和步骤回传给界面。WebView2 只加载应用自带的本地页面，不向页面开放任意文件或系统调用。

## 三、核心模块

### 1. 窗口管理

- 列出可见的顶层窗口，展示标题和所属程序供用户选择。
- 运行时保存窗口句柄与进程标识，并在每次录制、回放前确认它仍指向原窗口；脚本文件只保存可用于重新选择窗口的程序信息和标题提示，不持久化窗口句柄。
- 录制点击时把屏幕坐标换算成目标窗口内容区坐标。回放时反向换算，因此窗口移动后仍可使用；内容区尺寸改变时先停止并提示重新录制或调整步骤。

### 2. 录制器

- 仅在录制状态启用键盘和鼠标监听。回调只收集事件并快速返回，步骤整理放在后台队列处理。
- 只接受目标窗口位于前台时发生的事件；过滤执行快捷键和程序自身注入的输入，避免录入控制键或重复事件。
- 将点击、双击、滚轮、按键、组合键以及相邻步骤的间隔整理为脚本步骤。录制暂停时不保存任何输入。
- 第一版把中文等输入法文字作为可手动添加或编辑的“输入文字”步骤；不保证仅凭物理按键事件还原输入法最终文字。

### 3. 快捷键与执行器

- 用 Windows 全局快捷键机制注册用户选择的按键；默认 F10，注册失败时要求换键。F12 为系统保留键，不提供为正式版全局快捷键。
- 快捷键在待机状态启动，在执行状态停止；执行线程使用可取消任务，不能并行启动第二次。
- 每一步执行前检查目标窗口是否存在、身份是否匹配且处于前台，再按保存的时间间隔发送模拟输入。停止、窗口失焦、关闭或尺寸变化时立即取消剩余步骤，并释放仍处于按下状态的按键。
- 不自动强行切换窗口，不尝试向后台窗口或权限高于本程序的窗口发送操作。

### 4. 状态与脚本存储

内部状态限定为：`待机 → 录制 → 暂停/待机`，以及 `待机 → 执行 → 待机`。界面只显示宿主确认后的状态，避免按钮显示与实际录制或执行状态不一致。

脚本采用带版本号的 JSON。字段至少包括脚本名称、目标程序提示、快捷键、窗口内容区尺寸和步骤列表。步骤以明确类型保存，例如点击坐标、滚动量、按键组合、文本内容和等待毫秒数；加载时验证字段与数值范围。保存时先写临时文件，再替换旧文件，避免中途退出损坏脚本。脚本文件只允许数据步骤，不执行任意代码。

脚本内容以本地文件保存，MVP 不承诺对文本内容加密。界面须提醒用户暂停录制敏感输入，并在保存前检查步骤。

## 四、实现顺序

1. **桌面框架**：把 HTML Demo 放入 WebView2，打通界面与宿主的消息和状态更新。
2. **窗口与快捷键**：完成目标窗口选择、前台判断、快捷键注册与冲突提示。
3. **录制与回放**：先支持点击、按键、滚轮和等待时间，再加入暂停、停止和失焦保护。
4. **编辑与保存**：完成步骤列表编辑、JSON 读写及重新载入。
5. **打包与验收**：生成 Windows 安装包，检查 WebView2 Runtime 是否可用。

## 五、验证标准

- **自动测试**：覆盖脚本读写与校验、事件到步骤的转换、状态切换、停止与重复启动规则。
- **桌面验收**：在记事本等普通窗口完成录制、保存、重启工具、回放和快捷键停止。
- **异常验收**：验证窗口失焦、窗口关闭、尺寸变化、快捷键冲突、脚本损坏及回放中停止。
- **兼容性检查**：检查不同缩放比例与多显示器下的坐标；分别验证普通按键、组合键和手动文本步骤。

## 六、已知限制与后续方向

坐标步骤依赖窗口内容布局，界面变化后可能需要重新录制。Windows 模拟输入受权限级别限制，因此管理员权限窗口不纳入 MVP。后续可评估 UI Automation 控件定位、中文输入自动识别、循环和条件执行，但不影响第一版核心流程。
